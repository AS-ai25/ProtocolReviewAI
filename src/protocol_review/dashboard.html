Multi-Agent Architecture

Four cooperating agent roles. This is an explanatory view, not an active run.

01 · Coordinator

Prepares the protocol, manages the workflow and brings the findings together for the final decision and report.

02 · Administrative Reviewer

Checks administrative completeness and requirements. The normal workflow can stop at the administrative gate.

03 · Scientific Reviewer

Reviews scientific and methodological issues using the project knowledge bases and relevant protocol evidence.

04 · Scientific Critic

Challenges the scientific findings and may request a revision. This improves scrutiny but does not replace expert verification.

Tools (v1.7): deterministic evidence checks run in code around every LLM call (quote located, guideline code valid, absence search over the whole protocol, mention is not evidence, duplicate merge). In the tool-use configurations (2', 3', 4') the scientific reviewer, the critic and the single agent also call tools themselves: search_protocol, get_page, get_section, registry_field, kb_lookup, power_calc; the code checks still run afterwards. An agent that did not run never lets the decision end in PASS.
How to interpret evidence: a finding marked verified by automated checks is not necessarily clinically or scientifically correct. Human review remains essential.
